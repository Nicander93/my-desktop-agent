# 历史文档

本目录保存已被替代但仍有追溯价值的项目级文档。归档内容不是当前实现或规范的依据；当前行为以源码、测试和活跃专题文档为准。

文档满足以下条件之一时才归档：

- 已有新的权威文档明确替代它；
- 阶段性计划已经完成或取消，内容不再指导后续工作；
- 文档描述的是历史方案，保留目的仅为追溯决策。

归档前必须确认替代文档，更新所有仍需使用的入口和链接，并确保 Agent 的任务路由不再把旧文档列为当前规范。仅因文件较旧、命名不一致或内容暂时无人维护，不能直接归档。

领域内部已有归档目录时继续就近维护，例如 `docs/eval/archive/`；不要为了统一目录移动仍有有效引用的历史材料。
